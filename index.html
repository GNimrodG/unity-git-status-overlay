Git Status Overlay

Version 1.1.0 · VPM package com.data-unknown.git-status-overlay

VS Code-style git status inside the Unity editor: U/M/D letters in the Project window, changed GameObjects and prefab-instance overrides in the Hierarchy (diffed from the scene YAML), changed properties in the Inspector, and prefab overrides at a glance.

Add to VCC / ALCOM

The button opens VRChat Creator Companion or ALCOM. If nothing happens, add this repository by hand (Settings → Packages → Add Repository):

https://raw.githubusercontent.com/GNimrodG/unity-git-status-overlay/vpm/index.json
